# bb-plugin-office-files

Файловый менеджер офиса для BB: дерево папок и файлов сервера, открывается
как вкладка в правой панели треда (`threadPanelAction`) — рядом с разговором,
а не отдельным окном.

- `contract.ts` — общие типы между сервером и хостовым воркером.
- `host.ts` — полнодоверенный Node-воркер, который bb запускает прямо на
  подключённой машине офиса. Только здесь есть настоящий доступ к `fs`:
  читает директории (включая скрытые папки вроде `.claude`, `.agents`) и
  содержимое файлов.
- `server.ts` — backend-плагин: выбирает нужную машину (host) и отдаёт RPC
  фронтенду поверх `bb.hosts.experimental_client`.
- `app.tsx` — панель: дерево слева (ленивая подгрузка папок), превью файла
  справа.

## Поиск по имени

Строка поиска в шапке дерева: от двух символов панель показывает плоский
список совпадений по всему офису (имя + папка, в которой файл лежит) вместо
дерева. Обход делает `host.ts` НА машине офиса (`searchFiles` в контракте) —
иначе каждая папка стоила бы отдельного round trip до bb-сервера на Маке.
Регистр не важен, кириллица работает, `.git`/`node_modules`/кэши пропускаются,
потолок — 300 совпадений и 200 000 просмотренных записей, дальше `truncated`.
По симлинк-папкам обход не идёт, поэтому циклов быть не может.

## Вставить путь в сообщение

Кнопка с облачком у файла (в дереве, в результатах поиска, в шапке превью)
дописывает абсолютный путь в черновик текущего треда через `useComposer()` и
ставит туда фокус — вместо «скопировать путь» и ручной вставки.

## Скачивание файла из офиса

У каждого файла в дереве (по наведению) и в шапке превью есть кнопка со
стрелкой вниз — файл скачивается к владельцу на машину. Это обычная ссылка на
роут плагина `GET /api/v1/plugins/office-files/http/download?path=<абсолютный
путь>`, поэтому передачей занимается сам браузер: прогресс, диалог сохранения,
докачка. Байты лежат на машине офиса, а bb-сервер на Маке, поэтому роут тянет
их у `host.ts` кусками по 2 МБ и сразу отдаёт в поток — целиком в памяти файл
не собирается ни на одной стороне, и размер не ограничен (видео, архивы,
дампы). Путь по-прежнему проверяется `resolveWithin`: за корень офиса выйти
нельзя. Кнопка работает и для файлов, которые не показываются в превью
(бинарники, «слишком большой файл»).

## Настройки

```
bb plugin config office-files
bb plugin config office-files set rootPath /home/aikomanda/neuroshtab
bb plugin config office-files set hostId host_xxxxxxxx   # точный выбор машины
bb plugin reload office-files
```

По умолчанию плагин сам находит подключённую машину офиса по подстроке имени
(`hostMatch`, по умолчанию `fastvps`). Если машин несколько и подстрока не
совпала — укажи `hostId` явно (`bb machine list` покажет id).

## Установка

```
bb plugin install git:https://github.com/leonovs0808-star/bb-plugin-office-files.git
```

После правок:

```
bb plugin build .
bb plugin reload office-files
```
